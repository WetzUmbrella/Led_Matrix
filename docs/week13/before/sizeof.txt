# When the host value equals the Xtensa value: only if the field types and the packing are the same on both.
# They are the same here by construction:
#   - both structs carry __attribute__((packed)) (panel_sync.c:52 and :65), so GCC inserts no padding
#     between fields or at the end on any target; sizeof is the plain sum of the field sizes;
#   - every field is an exact-width <stdint.h> type (uint32_t is exactly 4 B, uint8_t exactly 1 B on every
#     target that defines them); there is no int, long, enum, pointer, bool or bit-field whose size could differ;
#   - MAX_NODES is the same macro value (8) on both builds.
# The ESP-IDF compiler (xtensa-esp32s3-elf-gcc) is GCC and honours the packed attribute, so the Xtensa value
# should equal the host value. The target-compiler confirmation is BENCH.md step S-2 (sizeof_xtensa.txt);
# until it runs, the "on target" cells in before_after.md stay blank.
